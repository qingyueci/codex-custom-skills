# Codex Custom Skills

我的两个自制 Codex skill：

- [`web-design-1`](skills/web-design-1)：构建、优化、验收并交付沉浸式图片与视频叙事网站。
- [`simple-poem-against`](skills/simple-poem-against)：按原文气质选择保留、哲思或讽刺，并生成诗歌 zine 海报。

## 目录

```text
skills/
├── web-design-1/
└── simple-poem-against/
```

## 使用

将对应目录复制到 Codex 的 skills 目录，或按 Codex skill 安装方式引用。每个 skill 的入口文件都是 `SKILL.md`，其附加规则位于同目录的 `references/` 和 `agents/`。

## 来源

这两个目录来自本地 Codex skills：`web-design-1` 与 `simple-poem-against`。原始本地目录保持不变。
